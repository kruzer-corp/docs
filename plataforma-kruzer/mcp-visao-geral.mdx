A documentação da Kruzer expõe um **servidor MCP** (Model Context Protocol) que permite a assistentes de IA — como Claude, Cursor, GitHub Copilot e ChatGPT — consultar todo o conteúdo desta doc em tempo real, com citações às páginas originais.

Em vez de copiar e colar trechos da doc no chat, você conecta o MCP uma única vez e seu assistente passa a ter acesso direto a Plataforma, DevTools (iPaaS, API Gateway, CLI, IDK) e PIM, incluindo a referência da API.

## O que é MCP

O **Model Context Protocol** é um padrão aberto que define como assistentes de IA conversam com fontes externas de contexto (documentação, bancos de dados, APIs, sistemas internos). Um servidor MCP exibe ferramentas e recursos; o cliente (Claude, Cursor, etc.) decide quando consultá-los durante a conversa.

O servidor MCP da Kruzer é **gerado automaticamente** pela Mintlify a partir desta documentação. Sempre que uma página é atualizada, o MCP reflete a mudança.

## Servidor da Kruzer

<CardGroup cols={1}>
  <Card title="Endpoint público" icon="link">
    `https://docs.kruzer.ai/mcp`
  </Card>
</CardGroup>

- **Transporte:** HTTP remoto (SSE) — não há binário para instalar localmente.
- **Autenticação:** não requer credenciais; o conteúdo é público.
- **Cobertura:** Plataforma, DevTools, PIM (incluindo a referência da API gerada do OpenAPI).

## Como funciona na prática

<Steps>
  <Step title="Você conecta o MCP no seu assistente">
    Adiciona a URL `https://docs.kruzer.ai/mcp` no cliente (Claude, Cursor, VS Code, ChatGPT). Veja [Conectar o MCP](/plataforma-kruzer/mcp-instalacao).
  </Step>
  <Step title="Faz uma pergunta normal">
    Ex.: *"Como configuro um trigger HTTP que consome uma fila Mongo na Kruzer?"*
  </Step>
  <Step title="O assistente busca na doc">
    O cliente decide consultar o MCP, recupera as páginas relevantes (Triggers, Consumers, MongoDB data source) e responde com base nelas — citando os links originais.
  </Step>
</Steps>

<Tip>
  As respostas vêm com referências às páginas usadas, então é fácil aprofundar clicando no link citado.
</Tip>
